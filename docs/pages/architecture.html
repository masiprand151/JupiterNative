Architecture

TypeScript source in src/ is bundled into runtime/App.js.
ClearScript V8 executes the bundle and exposes NativeBridge.
LayoutRenderer converts the UI tree into WPF controls.
src/entry.ts -> packages/core -> runtime/App.js
-> ClearScript V8 -> NativeBridge -> LayoutRenderer -> WPF

The current renderer performs full tree updates. Native inputs with stable IDs are detached and reused safely.
