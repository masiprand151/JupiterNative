Troubleshooting

Only one control is visible

Modal content must be rendered as an overlay while normal children remain in a panel.

Slider logical-parent error

Give the slider a stable id. The bridge detaches old sliders before reuse.

Console output is missing

Run the app from a terminal. The GUI runtime attaches to its parent console.

Transparency is not allowed

Check WPF window style and rendering mode. Unsupported combinations are rejected by WPF.
