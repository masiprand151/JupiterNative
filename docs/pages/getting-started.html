Getting started

Jupiter is a TypeScript desktop framework that renders JSX components into native Windows WPF controls.

Install and run

npm.cmd install
npm.cmd run doctor
npm.cmd run typecheck
npm.cmd run dev

First component

import { Button, Text, View } from "@jupiter/core";
export function HomeScreen() {
  return <View padding={16} gap={8}>
    <Text>Hello Jupiter</Text>
    <Button title="Click me" onPress={() => console.log("clicked")} />
  </View>;
}
